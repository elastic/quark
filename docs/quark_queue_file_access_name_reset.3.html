QUARK_QUEUE_FILE_ACCESS_NAME_RESET(3) Library Functions Manual QUARK_QUEUE_FILE_ACCESS_NAME_RESET(3)

NAME

quark_queue_file_access_name_reset — clear file access names and start a new report generation

SYNOPSIS

#include <quark.h>

int
quark_queue_file_access_name_reset(struct quark_queue *qq);

DESCRIPTION

Removes all file access names from a queue opened with QQ_FILE_ACCESS and starts a new generation for repeated-open suppression. After a successful reset, add the replacement names with quark_queue_file_access_name_add(3). A process can then report an access class again, including a class reported before the reset for the same file and path.

Reset and addition are separate operations. Opens while the name set is empty are not reported. An open already in progress, or an event already in the queue, can still refer to the previous name set. Reset does not remove queued events.

As with other operations on a queue, the caller must serialize reset and name addition, including calls from processes that inherit the queue. An error can leave only some names removed. The queue remains usable; retry reset before adding replacement names.

RETURN VALUES

Zero on success, -1 on error with errno set.

ERRORS

EINVAL
The queue does not have QQ_FILE_ACCESS with the eBPF backend.
EOVERFLOW
The generation reached its maximum value. The names remain unchanged.
